# V写作 Android MVP

一个 Flutter 本地版安卓 APP 原型，面向网络小说与设定集创作。

## 已包含
- 欢迎页
- 首页 / 作品列表
- 作品编辑器
- 大纲页面
- 设定集页面
- 统计页面
- 我的页面
- 统一蓝色设计系统
- 纯本地 Demo 数据，无服务器依赖

## 运行方式
```bash
flutter pub get
flutter run
```
